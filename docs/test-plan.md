# 测试计划

本文档记录 EveryCent 课程设计阶段需要覆盖的主要测试内容。

## 用户登录测试

- 使用 `admin/admin` 登录，验证管理员权限页面可访问。
- 使用 `user/user` 登录，验证普通用户只能访问授权页面。
- 输入错误密码，验证登录失败提示。

## 账本 CRUD 测试

- 创建个人账本。
- 查询当前用户账本列表。
- 修改账本名称和描述。
- 删除无记录账本或验证有关联记录时的删除限制。

## 多用户权限测试

- 账本所有者可授权其他用户。
- 只读用户不能新增或修改收支记录。
- 共同记账用户可以新增记录但不能修改账本所有者。
- 未授权用户不能访问账本详情和记录列表。

## 收支记录完整性约束测试

- 金额不能为空且必须大于 0。
- 收支类型只能为收入或支出。
- 行为标签和情绪标签必须在枚举范围内。
- 收支记录必须关联有效账本。
- 删除账本或用户时验证外键约束和业务限制。

## 预算超支测试

- 设置月预算后新增支出，验证已用预算更新。
- 支出接近预算上限时返回风险提醒。
- 支出超过预算时返回超支告警。
- 不同账本、不同月份预算互不影响。

## LLM 解析异常测试

- 输入正常自然语言，验证能解析金额、类型、行为标签和情绪标签。
- 输入缺少金额的文本，验证需要人工确认。
- LLM 超时或返回非 JSON，验证降级为手动表单。
- LLM 返回非法标签，验证后端拒绝或映射为默认值。

## Excel 导出测试

- 导出指定账本和月份账单。
- 验证文件格式、表头、金额、日期和备注正确。
- 验证无权限用户不能导出他人账本。

## 数据看板展示测试

- 验证收入、支出、余额汇总正确。
- 验证分类占比与收支记录一致。
- 验证空数据月份显示为空状态。
- 验证前端图表在桌面和移动端布局正常。
