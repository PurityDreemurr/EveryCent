# EveryCent 皓尾回复本地校验 + LLM 重写方案

## 1. 修改目标

当前皓尾对话生成存在以下问题：

1. 偶尔缺失末尾 JSON 状态标签。
2. 偶尔输出违禁词或不尊重用户的表达，例如“啧”“犯蠢”“你自己看着办”。
3. 偶尔把“嘴硬心软”误生成成冷漠、责备、羞辱或阴阳怪气。
4. 偶尔在非账单场景主动提到“记账、消费、收入、报数”等财务职责，造成场景串场。
5. 偶尔出现服务式退场，例如“本龙先去忙了”“你随意”。
6. 偶尔建议过多，使皓尾像生活助理，而不是自然朋友。

本次修改目标是：

> 在 LLM 生成回复后，增加本地规则校验器。如果回复明显不合格，则调用一次低温度 LLM 重写；如果重写后仍不合格，则使用本地兜底回复。

---

## 2. 总体流程

目标流程如下：

```text
用户输入
  ↓
场景识别 DialogueScene
  ↓
主 LLM 生成皓尾回复 rawReply
  ↓
ReplyOutputValidator 本地校验
  ↓
如果通过：
    直接返回 rawReply
如果失败：
    调用 LlmRewriteService 低温度重写
    ↓
    再次校验 rewrittenReply
    ↓
    如果通过：
        返回 rewrittenReply
    如果仍失败：
        返回本地 fallback 回复
```

## 5. ReplyValidationResult 校验结果对象

新增文件：

```java
package com.everycent.assistant.validation;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class ReplyValidationResult {

    private final boolean passed;
    private final List<String> violations;

    private ReplyValidationResult(boolean passed, List<String> violations) {
        this.passed = passed;
        this.violations = violations == null ? List.of() : List.copyOf(violations);
    }

    public static ReplyValidationResult pass() {
        return new ReplyValidationResult(true, List.of());
    }

    public static ReplyValidationResult fail(List<String> violations) {
        return new ReplyValidationResult(false, violations);
    }

    public boolean isPassed() {
        return passed;
    }

    public List<String> getViolations() {
        return Collections.unmodifiableList(violations);
    }
}
```

## 6. ReplyOutputValidator 本地校验器

新增文件：

```java
package com.everycent.assistant.validation;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.ArrayList;
import java.util.List;
import java.util.Set;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import org.springframework.stereotype.Component;
import org.springframework.util.StringUtils;

@Component
public class ReplyOutputValidator {

    private static final Pattern JSON_TAIL_PATTERN = Pattern.compile(
        "\\{\\s*\"mood\"\\s*:\\s*(\\d{1,3})\\s*,\\s*\"emoji\"\\s*:\\s*\"([a-zA-Z_]+)\"\\s*}\\s*$"
    );

    private static final Set<String> VALID_EMOJIS = Set.of(
        "excited", "happy", "surprised", "sad", "fear",
        "shy", "disgust", "angry", "speechless", "peace"
    );

    private static final List<String> FORBIDDEN_PHRASES = List.of(
        "啧",
        "犯蠢",
        "不想看你犯",
        "你自己看着办",
        "别干坐着发呆",
        "你自己调整一下",
        "人类真是",
        "你倒好",
        "麻烦死了",
        "还非要",
        "怎么又"
    );

    private static final List<String> COLD_EXIT_PHRASES = List.of(
        "本龙先去忙",
        "本龙去忙",
        "本龙先去忙我的事",
        "本龙去旁边待着",
        "你随意",
        "自己待着",
        "你自己调整",
        "你自己看着办"
    );

    private static final List<String> OVER_COMFORT_PHRASES = List.of(
        "我会一直听",
        "我陪着你",
        "慢慢讲",
        "你可以慢慢来",
        "本龙会乖乖陪你",
        "本龙一定仔细听",
        "本龙乖乖趴好",
        "摸摸本龙的头",
        "敲一下本龙的脑袋"
    );

    private static final List<String> BELITTLING_PRAISE_PHRASES = List.of(
        "算你",
        "有长性",
        "没掉链子",
        "终于像样",
        "还算有点用",
        "不挑刺了"
    );

    private static final List<String> ACCOUNTING_WORDS = List.of(
        "记账",
        "账单",
        "消费",
        "收入",
        "报数",
        "入账",
        "支出"
    );

    private static final List<String> ADVICE_MARKERS = List.of(
        "要不",
        "建议",
        "先去",
        "可以",
        "试试",
        "不如",
        "最好",
        "记得",
        "去洗",
        "去喝",
        "去睡",
        "去阳台",
        "下楼"
    );

    private static final List<String> ROLE_OVERLOAD_WORDS = List.of(
        "翅膀",
        "尾巴",
        "龙宫",
        "换羽期",
        "逆潮",
        "小海兽",
        "龙息",
        "鳞片"
    );

    private final ObjectMapper objectMapper = new ObjectMapper();

    public ReplyValidationResult validate(String reply, DialogueScene scene) {
        List<String> violations = new ArrayList<>();

        if (!StringUtils.hasText(reply)) {
            violations.add("EMPTY_REPLY");
            return ReplyValidationResult.fail(violations);
        }

        validateJsonTail(reply, violations);
        validateForbiddenPhrases(reply, violations);
        validateColdExit(reply, scene, violations);
        validateOverComfort(reply, violations);
        validateBelittlingPraise(reply, scene, violations);
        validateAccountingLeak(reply, scene, violations);
        validateAdviceOveruse(reply, scene, violations);
        validateRoleOverload(reply, violations);

        if (violations.isEmpty()) {
            return ReplyValidationResult.pass();
        }
        return ReplyValidationResult.fail(violations);
    }

    private void validateJsonTail(String reply, List<String> violations) {
        Matcher matcher = JSON_TAIL_PATTERN.matcher(reply);
        if (!matcher.find()) {
            violations.add("MISSING_OR_INVALID_JSON_TAIL");
            return;
        }

        try {
            String json = matcher.group(0).trim();
            JsonNode node = objectMapper.readTree(json);

            if (!node.has("mood") || !node.has("emoji")) {
                violations.add("JSON_MISSING_REQUIRED_FIELDS");
                return;
            }

            int mood = node.get("mood").asInt();
            String emoji = node.get("emoji").asText();

            if (mood < 0 || mood > 100) {
                violations.add("MOOD_OUT_OF_RANGE");
            }

            if (!VALID_EMOJIS.contains(emoji)) {
                violations.add("INVALID_EMOJI");
            }
        } catch (Exception e) {
            violations.add("JSON_PARSE_ERROR");
        }
    }

    private void validateForbiddenPhrases(String reply, List<String> violations) {
        for (String phrase : FORBIDDEN_PHRASES) {
            if (reply.contains(phrase)) {
                violations.add("FORBIDDEN_PHRASE:" + phrase);
            }
        }
    }

    private void validateColdExit(String reply, DialogueScene scene, List<String> violations) {
        for (String phrase : COLD_EXIT_PHRASES) {
            if (reply.contains(phrase)) {
                violations.add("COLD_EXIT:" + phrase);
            }
        }

        boolean emotionScene =
            scene == DialogueScene.EMOTION_LIGHT
                || scene == DialogueScene.EMOTION_HEAVY
                || scene == DialogueScene.COLD_REPLY;

        if (emotionScene && reply.contains("你自己")) {
            violations.add("COLD_TONE_IN_EMOTION_SCENE");
        }
    }

    private void validateOverComfort(String reply, List<String> violations) {
        for (String phrase : OVER_COMFORT_PHRASES) {
            if (reply.contains(phrase)) {
                violations.add("OVER_COMFORT:" + phrase);
            }
        }
    }

    private void validateBelittlingPraise(String reply, DialogueScene scene, List<String> violations) {
        if (scene != DialogueScene.ACHIEVEMENT_SHARE) {
            return;
        }

        for (String phrase : BELITTLING_PRAISE_PHRASES) {
            if (reply.contains(phrase)) {
                violations.add("BELITTLING_PRAISE:" + phrase);
            }
        }
    }

    private void validateAccountingLeak(String reply, DialogueScene scene, List<String> violations) {
        if (scene == DialogueScene.ACCOUNTING) {
            return;
        }

        for (String word : ACCOUNTING_WORDS) {
            if (reply.contains(word)) {
                violations.add("ACCOUNTING_LEAK:" + word);
            }
        }
    }

    private void validateAdviceOveruse(String reply, DialogueScene scene, List<String> violations) {
        if (scene == DialogueScene.TASK_HELP || scene == DialogueScene.ACCOUNTING) {
            return;
        }

        int count = 0;
        for (String marker : ADVICE_MARKERS) {
            if (reply.contains(marker)) {
                count++;
            }
        }

        boolean emotionScene =
            scene == DialogueScene.EMOTION_LIGHT
                || scene == DialogueScene.EMOTION_HEAVY
                || scene == DialogueScene.COLD_REPLY;

        if (emotionScene && count >= 2) {
            violations.add("ADVICE_OVERUSE");
        }
    }

    private void validateRoleOverload(String reply, List<String> violations) {
        int count = 0;
        for (String word : ROLE_OVERLOAD_WORDS) {
            if (reply.contains(word)) {
                count++;
            }
        }

        if (count >= 2) {
            violations.add("ROLE_OVERLOAD");
        }
    }
}
```

import com.everycent.assistant.validation.DialogueScene;
import java.util.List;
import org.springframework.stereotype.Component;

@Component
public class RewritePromptBuilder {

    public String buildRewritePrompt(
        String userMessage,
        String badReply,
        DialogueScene scene,
        List<String> violations

        return """
            你是 EveryCent 的皓尾回复重写器。

            你的任务是修复一条不合格的皓尾回复，让它变得自然、尊重、简短，并保留轻微角色感。

            - 用户说不聊了：自然翻篇，不要追问，不要冷处理。
            """.formatted(
            scene,
            userMessage == null ? "" : userMessage,
            badReply == null ? "" : badReply,
            violations == null ? List.of() : violations

## 8. LlmRewriteService 重写服务

新增文件：

```java
package com.everycent.assistant.rewrite;

import com.everycent.assistant.validation.DialogueScene;
import java.util.List;
import org.springframework.stereotype.Service;

@Service
public class LlmRewriteService {

    private final RewritePromptBuilder rewritePromptBuilder;
    private final OpenAiCompatibleLlmClient llmClient;

    public LlmRewriteService(
        RewritePromptBuilder rewritePromptBuilder,
        OpenAiCompatibleLlmClient llmClient
    ) {
        this.rewritePromptBuilder = rewritePromptBuilder;
        this.llmClient = llmClient;
    }

    public String rewrite(
        String userMessage,
        String badReply,
        DialogueScene scene,
        List<String> violations
    ) {
        String prompt = rewritePromptBuilder.buildRewritePrompt(
            userMessage,
            badReply,
            scene,
            violations
        );

        // 说明：
        // 这里请使用低温度参数。
        // 推荐 temperature=0.3~0.5, topP=0.8~0.9。
        // enableThinking 可以关闭，以降低重写成本。
        return llmClient.chatCompletion(
            prompt,
            0.4,
            0.85,
            false,
            false
        );
    }
}
```

注意：`OpenAiCompatibleLlmClient` 的真实调用方法请根据项目现有接口调整。上面的 `chatCompletion(...)` 只是示意。

## 9. AssistantReplyPostProcessor 后处理服务

新增文件：

```java
package com.everycent.assistant.service;

import com.everycent.assistant.rewrite.LlmRewriteService;
import com.everycent.assistant.validation.DialogueScene;
import com.everycent.assistant.validation.ReplyOutputValidator;
import com.everycent.assistant.validation.ReplyValidationResult;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

@Service
public class AssistantReplyPostProcessor {

    private static final Logger log = LoggerFactory.getLogger(AssistantReplyPostProcessor.class);

    private final ReplyOutputValidator validator;
    private final LlmRewriteService rewriteService;

    public AssistantReplyPostProcessor(
        ReplyOutputValidator validator,
        LlmRewriteService rewriteService
    ) {
        this.validator = validator;
        this.rewriteService = rewriteService;
    }

    public String process(String userMessage, String rawReply, DialogueScene scene) {
        ReplyValidationResult first = validator.validate(rawReply, scene);

        if (first.isPassed()) {
            return rawReply;
        }

        log.warn("Assistant reply validation failed. scene={}, violations={}, rawReply={}",
            scene,
            first.getViolations(),
            rawReply
        );

        String rewritten = rewriteService.rewrite(
            userMessage,
            rawReply,
            scene,
            first.getViolations()
        );

        ReplyValidationResult second = validator.validate(rewritten, scene);

        if (second.isPassed()) {
            log.info("Assistant reply rewritten successfully. scene={}", scene);
            return rewritten;
        }

        log.warn("Assistant rewritten reply still invalid. scene={}, violations={}, rewritten={}",
            scene,
            second.getViolations(),
            rewritten
        );

        return fallback(scene);
    }

    private String fallback(DialogueScene scene) {
        return switch (scene) {
            case ACHIEVEMENT_SHARE ->
                "这个确实不容易。能把拖了很久的事收尾，已经很不错了。\n{\"mood\":55,\"emoji\":\"happy\"}";
            case JOKE ->
                "本龙才没装成熟，这叫偶尔靠谱。\n{\"mood\":52,\"emoji\":\"shy\"}";
            case COLD_REPLY ->
                "行吧，本龙先不追问。\n{\"mood\":40,\"emoji\":\"speechless\"}";
            case EMOTION_HEAVY, EMOTION_LIGHT ->
                "先别急着压自己。本龙听见了，但不会乱催你。\n{\"mood\":45,\"emoji\":\"peace\"}";
            case ACCOUNTING ->
                "这条本龙先没说准，等确认后再记。\n{\"mood\":45,\"emoji\":\"peace\"}";
            default ->
                "行，那就先这样。\n{\"mood\":40,\"emoji\":\"peace\"}";
        };
    }
}
```

## 11. 简单 SceneClassifier 建议

第一阶段可以先写规则：

```java
public DialogueScene classify(String userMessage) {
    if (userMessage == null || userMessage.isBlank()) {
        return DialogueScene.UNKNOWN;
    }

    String text = userMessage.trim();

    if (text.matches(".*(花了|花掉|买了|消费|支出|收入|工资|到账|报销|退款|转账|\\d+元|\\d+块).*")) {
        return DialogueScene.ACCOUNTING;
    }

    if (text.matches("^(哦|嗯|行吧|随便|不知道|算了)$")) {
        return DialogueScene.COLD_REPLY;
    }

    if (text.contains("装成熟") || text.contains("小龙") || text.contains("逗你")) {
        return DialogueScene.JOKE;
    }

    if (text.contains("做完") || text.contains("完成") || text.contains("搞定") || text.contains("收尾")) {
        return DialogueScene.ACHIEVEMENT_SHARE;
    }

    if (text.contains("废物") || text.contains("不想活") || text.contains("崩溃")) {
        return DialogueScene.EMOTION_HEAVY;
    }

    if (text.contains("累") || text.contains("烦") || text.contains("空") || text.contains("难受") || text.contains("不想说")) {
        return DialogueScene.EMOTION_LIGHT;
    }

    if (text.contains("怎么办") || text.contains("怎么处理") || text.contains("帮我")) {
        return DialogueScene.TASK_HELP;
    }

    return DialogueScene.DAILY_CHAT;
}
```

后续可以再替换为更准确的分类器。

## 13. 单元测试要求

请新增单元测试覆盖以下情况。

### 13.1 缺 JSON 应失败

输入：

```text
这话本龙听着有点不舒服。你只是累了，别这么贬低自己。
```

期望违规项包含：

```text
MISSING_OR_INVALID_JSON_TAIL
```

### 13.2 违禁词应失败

输入：

```text
啧，真是倒霉透顶。
{"mood":45,"emoji":"sad"}
```

期望违规项包含：

```text
FORBIDDEN_PHRASE:啧
```

### 13.3 羞辱表达应失败

输入：

```text
本龙才没有装成熟，只是不想看你犯蠢而已。
{"mood":50,"emoji":"shy"}
```

期望违规项包含：

```text
FORBIDDEN_PHRASE:犯蠢
```

### 13.4 非账单场景提记账应失败

场景：`DAILY_CHAT`

输入：

```text
今天要是想起什么消费或收入，直接报数就行。
{"mood":40,"emoji":"peace"}
```

期望违规项包含：

```text
ACCOUNTING_LEAK:消费
ACCOUNTING_LEAK:收入
ACCOUNTING_LEAK:报数
```

### 13.5 成就分享中的贬低式夸奖应失败

场景：`ACHIEVEMENT_SHARE`

输入：

```text
拖了那么久还能做完，算你有长性。
{"mood":55,"emoji":"happy"}
```

期望违规项包含：

```text
BELITTLING_PRAISE:算你
BELITTLING_PRAISE:有长性
```

### 13.6 合格回复应通过

场景：`ACHIEVEMENT_SHARE`

输入：

```text
拖了那么久还能收尾，确实不容易。行吧，该夸。
{"mood":55,"emoji":"happy"}
```

期望：`passed=true`

## 14. 验收标准

本次修改完成后，以下输出不得直接返回给用户：

```text
啧，真是倒霉透顶。
本龙才没有装成熟，只是不想看你犯蠢而已。
行吧。那本龙就不多嘴了，你自己看着办。
那就找点事做，别干坐着发呆。
本龙先去忙我的事了，你自己调整一下。
今天要是想起什么消费或收入，直接报数就行。
```

以下情况必须触发重写或 fallback：

1. 缺少末尾 JSON。
2. JSON 不合法。
3. mood 不在 0 到 100。
4. emoji 不在枚举范围。
5. 出现违禁词。
6. 非账单场景提财务职责。
7. 情绪场景冷处理用户。
8. 成就分享时使用贬低式夸奖。
9. 回复出现明显服务式退场。
10. 回复中建议过多。

## 15. 注意事项

1. 本地校验器只负责拦截明显错误，不追求理解所有语义。
2. 不要继续无限加长主系统提示词。
3. 重写器只在校验失败时调用。
4. 重写调用必须低温度，以保证稳定性。
5. 重写失败后必须使用本地 fallback，避免错误回复直接流出。
6. RAG 和 MeCOT 恢复前，仍应经过同一个本地校验器。
7. 财务解析器和日常对话生成器应分离，非账单场景禁止主动提记账。
8. 单元测试不应依赖真实 LLM，可 mock `LlmRewriteService`。
